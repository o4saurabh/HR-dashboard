
🚀 Project Overview

This dashboard provides a percentage-based analysis of employee working patterns. It helps HR teams track workforce distribution and make data-driven decisions using dynamic filtering and automated calculations.

The report is fully interactive and updates automatically based on slicer selections.

📌 Key Metrics Visualized

📈 Total Working Employees (%) – Percentage of employees actively working in the selected month

🏠 **Work From Home (WFH %) ** – Percentage of employees working remotely

🏥 **Sick Leave (SL %) ** – Percentage of employees on sick leave

📅 Month-wise Slicer – Dynamic filtering to analyze specific months

🛠 Tech Stack

Power BI – Data modeling & dashboard creation

Microsoft Excel – Data source & preprocessing

DAX (Data Analysis Expressions) – Custom measures & calculated fields

Parameters – Automated data summarization

⚙️ Features

✔ Interactive slicers for dynamic month selection
✔ Automated percentage calculations using DAX measures
✔ Clean KPI-based visualization
✔ Business-focused dashboard layout
✔ Real-time workforce trend analysis

📊 Business Impact

This dashboard enables HR teams to:

Monitor employee presence trends

Analyze WFH adoption patterns

Track sick leave behavior

Improve workforce planning

Support data-driven HR decisions
